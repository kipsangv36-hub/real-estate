# real estate Website

A front-end demo website recreated from the supplied PropertyTrack screenshots.

## Features
- Login screen
- Dashboard with listing statistics and alerts
- Property listings table
- Search listings
- Add and edit property listings
- Duplicate plot-number warning
- Change status / withdraw listings
- Activity log
- Reports centre
- Export stale listings to CSV
- Responsive layout for mobile screens

Open `index.html` in a web browser.
